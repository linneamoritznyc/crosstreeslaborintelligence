# Produktkravsdokument — Crosstrees Labor Intelligence v1

## Problemformulering

Den svenska arbetsmarknaden lider av strukturella matchningsproblem:
- Arbetsgivare hittar inte rätt kompetenser
- Medborgare saknar vägledning om karriärvägar och kompetensgap
- Regionala beslutsfattare har begränsad datadriven insikt om lokala bristyrken

## Målgrupper

### TalentFlow — medborgare
- Arbetssökande som vill förstå sin position på arbetsmarknaden
- Anställda som vill planera karriärbyte
- Nyexaminerade som söker sin första tjänst

### Kompetensgrafen — regionala tjänstemän
- Handläggare på Kompetensgrafen i Jönköpings län
- Beslutsfattare som behöver underlag för utbildningsinvesteringar

## Kärnfunktioner

### TalentFlow
1. CV-uppladdning och automatisk kompetensextraktion (Claude AI)
2. Jobbmatchning med förklarbart matchningspoäng (Wilson-CI)
3. Karriärgrafe med grannskapande yrken
4. Kompetensgapanalys mot målyrke
5. Utbildningsrekommendationer (Jobed Connect)

### Kompetensgrafen
1. Bristyrkesöversikt per sektor och kommun
2. Substitutabilitetskarta för omställningsplanering
3. ROI-kalkylator för utbildningsinvesteringar
4. AI-driven chattbot för arbetsmarknadsfrågor
5. PDF-rapportexport på svenska

## Framgångsmått

- Matchningsprecision: >70% användarnöjdhet med topp-3 jobbförslag
- API-svarstid: p95 <500ms för matchningsendpoints
- Datasäkerhet: 0 GDPR-incidenter
- AI Act-efterlevnad: 100% på kvartalsvisa revisioner
